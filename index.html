import ccxt import pandas as pd import numpy as np import time import logging import requests # НАСТРОЙКА ЛОГИРОВАНИЯ И ПАРАМЕТРОВ БОТА logging.basicConfig( level=logging.INFO, format='%(asctime)s [%(levelname)s] %(message)s', handlers=[logging.FileHandler("trading_bot.log"), logging.StreamHandler()] ) # НАСТРОЙКА TELEGRAM (вставь свои данные для отправки точных сигналов) TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN" TELEGRAM_CHAT_ID = "YOUR_CHAT_ID" def send_telegram_alert(message): if TELEGRAM_BOT_TOKEN == "YOUR_BOT_TOKEN": return url = f"https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage" payload = { 'chat_id': TELEGRAM_CHAT_ID, 'text': message, 'parse_mode': 'Markdown' } try: requests.post(url, json=payload, timeout=5) except Exception as e: logging.error(f"Ошибка отправки в Telegram: {e}") # ИНИЦИАЛИЗАЦИЯ БИРЖИ (Binance Futures для торговли в лонг и шорт) exchange = ccxt.binance({ 'enableRateLimit': True, 'options': {'defaultType': 'swap'} }) # 6 ВАЛЮТНЫХ ПАР PAIRS = [ 'BTC/USDT', 'ETH/USDT', 'SOL/USDT', 'BNB/USDT', 'XRP/USDT', 'ADA/USDT' ] # 5 ТАЙМФРЕЙМОВ: минута, 5 минут, час, 4 часа, дневка TIMEFRAMES = { '1m': '1 минута', '5m': '5 минут', '1h': '1 час', '4h': '4 часа', '1d': 'дневка' } # Кэш для предотвращения повторной отправки сигналов по одной и той же свече last_signal_timestamps = {} def fetch_ohlcv_data(symbol, timeframe, limit=300): try: ohlcv = exchange.fetch_ohlcv(symbol, timeframe, limit=limit) df = pd.DataFrame(ohlcv, columns=['timestamp', 'open', 'high', 'low', 'close', 'volume']) df['timestamp'] = pd.to_datetime(df['timestamp'], unit='ms') return df except Exception as e: logging.error(f"Ошибка загрузки данных {symbol} ({timeframe}): {e}") return None def calculate_all_indicators(df): # 1. Трендовые EMA (50 и 200) df['ema_50'] = df['close'].ewm(span=50, adjust=False).mean() df['ema_200'] = df['close'].ewm(span=200, adjust=False).mean() # 2. Осциллятор RSI (14) delta = df['close'].diff() gain = (delta.where(delta > 0, 0)).rolling(window=14).mean() loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean() rs = gain / loss df['rsi'] = 100 - (100 / (1 + rs)) # 3. MACD (12, 26, 9) exp1 = df['close'].ewm(span=12, adjust=False).mean() exp2 = df['close'].ewm(span=26, adjust=False).mean() df['macd'] = exp1 - exp2 df['macd_signal'] = df['macd'].ewm(span=9, adjust=False).mean() df['macd_hist'] = df['macd'] - df['macd_signal'] # 4. Полосы Боллинджера (20, 2) df['bb_middle'] = df['close'].rolling(window=20).mean() std = df['close'].rolling(window=20).std() df['bb_upper'] = df['bb_middle'] + (std * 2) df['bb_lower'] = df['bb_middle'] - (std * 2) # 5. Stochastic Oscillator (14, 3, 3) для отсечения ложных точек low_min = df['low'].rolling(window=14).min() high_max = df['high'].rolling(window=14).max() df['stoch_k'] = ((df['close'] - low_min) / (high_max - low_min)) * 100 df['stoch_d'] = df['stoch_k'].rolling(window=3).mean() # 6. ATR (Average True Range) для точного расчета Stop Loss и Take Profit df['tr1'] = abs(df['high'] - df['low']) df['tr2'] = abs(df['high'] - df['close'].shift()) df['tr3'] = abs(df['low'] - df['close'].shift()) df['tr'] = pd.concat([df['tr1'], df['tr2'], df['tr3']], axis=1).max(axis=1) df['atr'] = df['tr'].rolling(window=14).mean() return df def analyze_market_conditions(df, symbol, tf_key, tf_name): if df is None or len(df) < 250: return None last = df.iloc[-1] prev = df.iloc[-2] price = last['close'] atr = last['atr'] timestamp = last['timestamp'] # Уникальный ключ свечи для исключения дублирования сигналов signal_key = f"{symbol}_{tf_key}" if signal_key in last_signal_timestamps and last_signal_timestamps[signal_key] == timestamp: return None # ЖЕСТКАЯ МУЛЬТИ-ИНДИКАТОРНАЯ КОНФЛЮЭНТНОСТЬ ДЛЯ ВЫСОКОЙ ТОЧНОСТИ (Исключаем рандом) # Жесткие условия для ЛОНГА long_condition = ( (last['close'] > last['ema_50']) and (last['ema_50'] > last['ema_200']) and (prev['macd_hist'] <= 0 and last['macd_hist'] > 0) and (45 <= last['rsi'] <= 68) and (last['stoch_k'] > last['stoch_d']) and (last['stoch_k'] < 80) and (last['close'] > last['bb_middle']) ) # Жесткие условия для ШОРТА short_condition = ( (last['close'] < last['ema_50']) and (last['ema_50'] < last['ema_200']) and (prev['macd_hist'] >= 0 and last['macd_hist'] < 0) and (32 <= last['rsi'] <= 55) and (last['stoch_k'] < last['stoch_d']) and (last['stoch_k'] > 20) and (last['close'] < last['bb_middle']) ) if long_condition: last_signal_timestamps[signal_key] = timestamp stop_loss = price - (atr * 1.8) take_profit = price + (atr * 3.5) return { 'type': 'LONG', 'symbol': symbol, 'timeframe': tf_name, 'price': price, 'stop_loss': round(stop_loss, 4), 'take_profit': round(take_profit, 4), 'rsi': round(last['rsi'], 2), 'stoch': round(last['stoch_k'], 2) } elif short_condition: last_signal_timestamps[signal_key] = timestamp stop_loss = price + (atr * 1.8) take_profit = price - (atr * 3.5) return { 'type': 'SHORT', 'symbol': symbol, 'timeframe': tf_name, 'price': price, 'stop_loss': round(stop_loss, 4), 'take_profit': round(take_profit, 4), 'rsi': round(last['rsi'], 2), 'stoch': round(last['stoch_k'], 2) } return None def main_loop(): logging.info("ЗАПУСК ПРОФЕССИОНАЛЬНОГО ТОРГОВОГО БОТА В РЕЖИМЕ РЕАЛЬНОГО ВРЕМЕНИ...") print("Бот полностью запущен. Сканирование рынка по всем парам и таймфреймам активировано...") while True: for symbol in PAIRS: for tf_key, tf_name in TIMEFRAMES.items(): try: df = fetch_ohlcv_data(symbol, tf_key) if df is not None: df = calculate_all_indicators(df) signal = analyze_market_conditions(df, symbol, tf_key, tf_name) if signal: alert_text = ( f"🔥 **ТОЧНЫЙ СИГНАЛ В ТРЭЙДИНГЕ** 🔥\n\n" f"📊 Направление: **{signal['type']}**\n" f"🪙 Пара: `{signal['symbol']}`\n" f"⏱ Таймфрейм: `{signal['timeframe']}`\n" f"💰 Цена входа: `{signal['price']}`\n" f"🛑 Stop Loss: `{signal['stop_loss']}`\n" f"🎯 Take Profit: `{signal['take_profit']}`\n" f"📈 RSI: `{signal['rsi']}` | Stoch: `{signal['stoch']}`\n\n" f"🚀 Сделка подтверждена мульти-индикаторной системой фильтрации!" ) logging.info(f"СИГНАЛ ВЫДАН: {signal['type']} по {signal['symbol']} ({signal['timeframe']})") print("\n" + "="*50) print(alert_text.replace('**', '').replace('`', '')) print("="*50 + "\n") send_telegram_alert(alert_text) except Exception as e: logging.error(f"Ошибка в цикле обработки {symbol} / {tf_key}: {e}") time.sleep(0.4) # пауза для соблюдения лимитов биржи logging.info("МИКРОЦИКЛ ЗАВЕРШЕН. ОЖИДАНИЕ СЛЕДУЮЩЕГО ТАКТА...") time.sleep(15) if __name__ == "__main__": main_loop()
